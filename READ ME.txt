Quick Start:
--------------------------------------------------------------------------------
1. Install dependencies (Python >=3.10, <3.12):
     pip install -e ".[dev]"

2. Launch the Desktop GUI:
     python phacs_nmr.py
   (or: python phacs_nmr_gui.py / phacs-nmr-gui)

3. Run CLI Single-Spectrum or Batch Processing on 13C TopSpin ascii-spec.txt files:
     python phacs_nmr.py <file_or_folder_path> [noise_level_5_or_10]

4. Run the Automated Test Suite:
     pytest -v
