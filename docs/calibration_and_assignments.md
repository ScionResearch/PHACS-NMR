# Chemical Shift Assignments, Calibration & Spectral Processing

This document provides the complete reference for chemical shift assignments, peak-picking intervals, empirical $^1\text{H}$ deconvolution calibration factors, and input data specifications used across `PHACS-NMR`.

---

## 1. Input Data Specifications

All wet-lab sample preparation, spectrometer acquisition parameters (`zg30` / `zgig30`), and Bruker TopSpin preprocessing workflows (chemical shift calibration to TMS, phasing with `apk0`, baseline correction with `absn`, and deconvolution) are documented in **[Software Protocol v2.pdf](../Software%20Protocol%20v2.pdf)** [1].

`PHACS-NMR` directly ingests the exported ASCII files produced by TopSpin:

1. **$^1\text{H}$ Deconvolution Table (`dconpeaks.txt`)**:
   - Deconvoluted Lorentzian peak list generated by TopSpin's `dcon` command across the ester ($[4.0, 6.0]\text{ ppm}$), $\alpha$-methylene ($[2.0, 3.0]\text{ ppm}$), and methyl ($[0.5, 1.5]\text{ ppm}$) zones.
   - Expected file path: `<sample>/10/pdata/1/dconpeaks.txt`.
   - Parsed by [`core.io.results_dconv()`](../core/io.py#L209-L270) to identify monomers and apply empirical calibration constants.

2. **$^{13}\text{C}$ ASCII Spectrum (`ascii-spec.txt`)**:
   - Full 1D $^{13}\text{C}$ spectrum exported via TopSpin's `convbin2asc` command.
   - Expected file path: `<sample>/11/pdata/1/ascii-spec.txt` (a 4-column whitespace-delimited ASCII table where Column 1 is Intensity and Column 3 is Chemical Shift in $\text{ppm}$).
   - Parsed by [`core.io.load_ascii_spectrum()`](../core/io.py#L19-L44) for baseline noise estimation, peak picking, and Lorentzian lineshape deconvolution.

## 2. $^1\text{H}$ NMR Deconvolution & Empirical Calibration (`core/io.py`)

### 2.1 Monomer Peak Identification Windows
In [`find_monomers()`](../core/io.py#L80-L177), deconvoluted peak positions (`peaks_ppm`) from `dconpeaks.txt` are matched against three functional group regions:
- **`Est` ($\text{O-CH}$ / $\text{O-CH}_2$ Ester Region, $4.1\text{--}5.3\text{ ppm}$)**
- **`CH2` ($\alpha\text{-CH}_2$ Methylene Region, $2.3\text{--}2.6\text{ ppm}$)**
- **`Met` (Terminal $\text{-CH}_3$ Methyl Region, $0.87\text{--}1.28\text{ ppm}$)**

#### Three-Tier Zone Selection Logic
Because 4HB (`F`) lacks a methyl ($\text{-CH}_3$) group, `find_monomers()` executes a 3-step decision tree:
1. **Initial Screening (`Est` Zone)**: Scans $[4.1, 5.3]\text{ ppm}$ to detect whether 4HB (`p_id[0] == 1`) is present above a $1\%$ relative intensity threshold (`est_monomers_int[0] >= 0.01`).
2. **Case A — Significant 4HB Present (`>= 0.01`)**:
   - Re-evaluates monomer intensities in the **`CH2` zone** ($[2.0, 3.0]\text{ ppm}$).
   - If the polymer is strictly a binary P(3HB-co-4HB) copolymer (`p_id == [1, 1, 0, 0, 0, 0, 0, 0, 0]`), switches to the well-separated **`Est` zone** ($[4.0, 6.0]\text{ ppm}$).
3. **Case B — 4HB Absent or Trace (`< 0.01`)**:
   - Discards trace 4HB and quantifies all monomers in the high-intensity **`Met` ($\text{-CH}_3$) zone** ($[0.5, 1.5]\text{ ppm}$).

### 2.2 Empirical Deconvolution Calibration Constants
Unlike full multiplet integration, TopSpin's `dcon` peak table reports the height (`peaks_intensity`) of the central deconvoluted Lorentzian component of each multiplet (e.g., doublet for 3HB $\text{CH}_3$, triplet for 3HV/MCL $\text{CH}_3$, triplet for 4HB $\text{O-CH}_2$). Because proton count ($2\text{H}$ vs. $3\text{H}$), spin-spin multiplicity splitting ($d$ vs. $t$ vs. $ddq$), and line broadening differ across monomer groups, [`results_dconv()`](../core/io.py#L230-L257) applies empirical calibration factors calibrated against reference PHA standards on TopSpin 4.5.0:

| Detected Polymer (`p_id`) | Composition Formula Applied in [`core/io.py`](../core/io.py#L231-L256) | Physical & Empirical Rationale |
| :--- | :--- | :--- |
| **P(3HB-co-4HB)**<br>`[1, 1, 0, 0, 0, 0, 0, 0, 0]` | $$F_{\text{4HB}} = 0.5437 \cdot I_{\text{4HB}}$$<br>$$F_{\text{3HB}} = 1 - F_{\text{4HB}}$$ | Corrects for stoichiometric proton ratio ($2\text{H}$ on 4HB $\text{O-CH}_2$ triplet vs. $1\text{H}$ on 3HB $\text{O-CH}$ multiplet) and multiplet peak-height factor. |
| **P(3HB-co-4HB-co-3HV)**<br>`[1, 1, 1, 0, 0, 0, 0, 0, 0]` | $$F_{\text{4HB}} = 0.5437 \cdot I_{\text{4HB}}$$<br>$$F_{\text{3HV}} = I_{\text{3HV}}$$<br>$$F_{\text{3HB}} = 1 - (F_{\text{4HB}} + F_{\text{3HV}})$$ | Applies the 4HB methylene correction factor ($0.5437$) in the $\text{CH}_2$ region while preserving 3HV and computing 3HB by closure. |
| **P(3HB-co-3HV)**<br>`[0, 1, 1, 0, 0, 0, 0, 0, 0]` | $$F_{\text{3HV}} = 0.8401 \cdot I_{\text{3HV}}$$<br>$$F_{\text{3HB}} = 1 - F_{\text{3HV}}$$ | Corrects the central peak height of the 3HV $V_5$ methyl triplet ($0.89\text{ ppm}$) relative to the 3HB $B_4$ methyl doublet ($1.27\text{ ppm}$). |
| **P(3HB-co-3HHx-co-3HO)**<br>`[0, 1, 0, 1, 0, 1, 0, 0, 0]` | $$F_{\text{3HO}} = 1.1263 \cdot I_{\text{3HO}} + 0.0316$$<br>$$F_{\text{3HB}} = 1.0344 \cdot I_{\text{3HB}} - 0.0686$$<br>$$F_{\text{3HHx}} = 1 - (F_{\text{3HB}} + F_{\text{3HO}})$$ | Two-parameter linear regression calibration correcting partial overlap between 3HHx ($0.91\text{ ppm}$) and 3HO ($0.88\text{ ppm}$) terminal methyl triplets. |
| **General Multi-Monomer PHA**<br>(All other combinations) | $$F_{\text{4HB}} = 0.5437 \cdot I_{\text{4HB}}$$<br>$$F_{\text{3HB}} = 1 - \sum_{i \neq \text{3HB}} F_i$$ | Applies the $0.5437$ factor to 4HB (if present) and normalizes 3HB by mass balance closure if 3HB is present. |

## 5. Noise Calculation & Lineshape Fitting (`core/noise.py` & `core/peak_fitting.py`)

### 5.1 Baseline Noise Level Estimation
[`calc_noise_level()`](../core/noise.py#L18-L29) computes the root-mean-square (RMS) baseline noise in the signal-free spectral window between **$100.0\text{ ppm}$ and $110.0\text{ ppm}$**:

$$\sigma_{\text{noise}} = \sqrt{\frac{1}{N} \sum_{x_i \in [100, 110]} y_i^2}$$

### 5.2 Choosing the Noise Multiplier (`5` vs. `10`)
- **`multiple_noise = 5` (Clean Spectrum)**: Sets the peak detection threshold to $5 \sigma_{\text{noise}}$. Recommended for well-shimmed spectra with high scan counts ($4096\text{--}16384$ scans) or when quantifying minor monomer sequences ($2\text{--}5\%$).
- **`multiple_noise = 10` (Noisy Spectrum)**: Sets the peak detection threshold to $10 \sigma_{\text{noise}}$. Recommended for lower scan counts ($2048$ scans) or when baseline impurities cause false peak picking at factor $5$.

### 5.3 Lorentzian Lineshape Fitting & Integration
In [`peak_picking()`](../core/peak_fitting.py#L46-L163):
1. Candidate peaks are located via downward curvature search (`ng.peakpick.pick(..., algorithm='downward', lineshapes=['l'])`).
2. When multiple peaks fall within a single sub-assignment window $[x_{\text{min}}, x_{\text{max}}]$, the peak with the maximum intensity is selected as the primary resonance (`max_peak`).
3. Each spectral region is fitted with a sum of Lorentzian lineshapes via `nmrglue.linesh.fit_NDregion` using bounded Levenberg-Marquardt optimization (`±3` data points on center position $x_0$, half-width bounds $[0.1, 2\,\Delta w]$, amplitude bounds $[0, 1.2\,A_0]$).
4. The analytical integral under each fitted Lorentzian peak ($x \in [\text{start}, \text{end}]$) is evaluated in closed form:
   $$\text{Area} = \int_{x_{\text{start}}}^{x_{\text{end}}} \frac{A}{1 + \left(\frac{x - x_0}{w / 2}\right)^2} \, dx = \frac{A \cdot w}{2} \left[ \arctan\left(\frac{x_{\text{end}} - x_0}{w / 2}\right) - \arctan\left(\frac{x_{\text{start}} - x_0}{w / 2}\right) \right]$$
